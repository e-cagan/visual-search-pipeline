End-to-End Visual Search Engine

This repository implements a complete Content-Based Image Retrieval (CBIR) pipeline, from data ingestion and preprocessing to training a metric-learning model and running high-performance C++ inference at the edge.

Project overview

- Data ingestion: scripts fetch product images and metadata from public e‑commerce APIs and store them in a local SQLite database (metadata.db).
- Preprocessing: aspect-ratio preserving padding, alpha-channel blending for transparent images, and pixel-variance filtering to remove corrupted/low-quality images.
- Model training: ResNet-18 backbone used as a feature extractor in a Siamese metric-learning setup with a 512-dim L2-normalized embedding and a Triplet Margin Loss. AMP (FP16) is supported for memory-efficient training.
- Deployment: model exported to ONNX and served by a C++ inference engine (ONNX Runtime) with an in-memory KNN search using dot-product similarity on L2-normalized vectors.

Repository structure (high level)

- scripts/                : data collection and basic image processing utilities
- src/preprocessing/      : image cleaning and augmentation helpers
- src/models/             : model definitions (backbone, projection head)
- src/training/           : training scripts and loss implementations
- src/inference/          : ONNX export and C++ inference glue
- lib/                    : C++ helper libraries and KNN implementation
- metadata.db             : SQLite database produced by the scraper (generated)

Tech stack

- Python 3, OpenCV, SQLite3, Requests
- PyTorch, Torchvision
- C++17, ONNX Runtime (C++ API), CMake

Quick start

1) Data collection and preprocessing

	# Fetch raw images and build SQLite database
	python3 scripts/run_scraper.py

	# Clean images (padding, blending, variance check)
	python3 scripts/process_data.py

2) Train and export model

	# Train the Siamese network (Triplet Loss)
	python3 src/training/train.py

	# Export trained weights to ONNX
	python3 src/inference/export_onnx.py

3) Build and run C++ inference

	mkdir build && cd build
	cmake ..
	make -j$(nproc)

	# Run the inference engine
	./inference_engine

Notes

- The ONNX model filename used by the C++ engine is visual_search_model.onnx (generated by export_onnx.py).
- The C++ KNN implementation assumes L2-normalized embeddings and uses dot-product for fast similarity.
- Adjust training hyperparameters and dataset paths in src/training/train.py as needed.
